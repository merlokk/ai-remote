Restart

up

Anything set and not saved is lost. Settings typed on the console live in memory until config save writes them, and a restart is exactly where they go — including this site's own mode and password.

It comes back in about ten seconds. The enrolment and the registration are files and survive it, so the device is answering requests again as soon as it has a network and the key is on the port.

What happens

keepsthe enrolment, the registration, and everything in config.json
losessettings that were never saved, the uptime, and the heap low-water mark
takesabout ten seconds, plus a few more to rejoin the network
There is no signing key on this board to lose — the private half lives inside the security key and is reconstructed there for each signature, so a restart cannot cost this device its identity. This page cannot switch the board off, only restart it; the RST button on the board does the same thing with no firmware involved.
