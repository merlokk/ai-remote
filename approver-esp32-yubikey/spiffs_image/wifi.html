Radio

Client joins one of the networks below, in turn. Access point makes this device its own network so a phone can reach this page with no other network around — which on a board with no screen is the only way in that needs no cable.

Networks

Up to four. The device tries them in order and falls back to its own access point when none of them answers.

This device's access point

What it puts on the air in access-point mode, and as the fallback when no network answers. Leave the password empty for an open network, or use eight characters or more — anything in between is refused by the radio.

Passwords are never sent back by the device, so a box left empty keeps the key it already has. Apply changes what is in memory; Apply and save writes config.json so it survives a restart. Reconnect now makes the radio walk the list again — if you are reading this over Wi-Fi, that is the button that can take the page away.
