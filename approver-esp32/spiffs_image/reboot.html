Restart

up

Anything set and not saved is lost. Settings typed on the console or picked on the device's own screen live in memory until config save writes them, and a restart is exactly where they go.

It comes back in about ten seconds. The registration and the key survive it, so the device is answering requests again as soon as it has a network.

What happens

keepsthe key, the registration, and everything in config.json
losessettings that were never saved, the uptime, and the heap low-water mark
takesabout ten seconds, plus a few more to rejoin the network
Holding PWR for six seconds switches the board off instead — that is the power chip's own behaviour and no firmware is involved in it. This page cannot switch the device off, only restart it.
